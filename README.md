## 🎯 Uses
This is the GitHub profile for **Elio Ucan**, a Data Engineering student at Universidad Politécnica de Yucatán (UPY), México. It serves as a landing page for recruiters, collaborators, and fellow engineers looking for a remote Data/AI/MLOps engineer. Every pinned repo documents a real, end-to-end project from the portfolio series.

## 🔧 Process
Built as a curated personal brand page to communicate a progressive Data/MLOps engineering journey. Each project in the portfolio series was designed to cover one new layer of the stack — from ETL to cloud deployment — and is linked directly from the profile.

## 💡 Learnings
- Communicating technical experience clearly through project portfolios is as important as the projects themselves
- A progressive series of projects (each building on the last) demonstrates growth more effectively than isolated experiments
